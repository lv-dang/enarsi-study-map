🧭 How to read ENARSI questions

"Troubleshoot"Most items show output. Find the one line that's wrong (state, counter, missing keyword) before reading the options. Stuck state = clueOSPF ExStart/Exchange → MTU · BGP Idle → no route/TTL/source · BGP Active → TCP fails · EIGRP SIA → query scope. "Most likely cause"Pick the cause that explains every symptom shown, not just one. "Without disruption"Soft reset, route-map change, conditional debug, not a reload or clear *. Order / match itemsConfig chains: ACL → class-map → policy-map → apply; record → exporter → monitor → interface; SLA → schedule → track → route. "Choose two"The two answers usually work together (redirect + shortcut, tag + deny).
